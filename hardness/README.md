# Hardness

Estrutura para classificar dificuldade, risco e profundidade de execucao das tarefas.

Use este diretorio antes de planejar mudancas relevantes. A classificacao ajuda o orquestrador a decidir quais agentes acionar, quanto contexto recuperar e quais verificacoes executar.

## Arquivos

- `hardness-matrix.md`: escala de dificuldade e criterios.
- `risk-signals.md`: sinais que aumentam risco ou exigem especialistas.
- `assessment-template.md`: modelo curto para registrar avaliacao.
