# RAG

Estrutura para Retrieval Augmented Generation do time de agentes.

Use este diretorio para orientar como recuperar, registrar e reutilizar contexto antes de tomar decisoes tecnicas.

## Arquivos

- `rag-playbook.md`: processo de recuperacao de contexto.
- `sources.md`: tipos de fontes aceitas e prioridade de confianca.
- `context-notes-template.md`: modelo para registrar contexto recuperado.

## Quando Usar

- Tarefas com regras espalhadas em varios arquivos.
- Mudancas que dependem de historico, padroes locais ou decisoes anteriores.
- Revisoes em que o impacto nao fica claro apenas pelo diff.
- Implementacoes em areas desconhecidas do repositorio.
